# 🧪 Локальное тестирование бота

Этот документ описывает, как настроить и запустить локальное тестирование бота перед пушем в продакшн.

## 📋 Требования

1. **Python 3.8+**
2. **Тестовый Telegram бот** (создать через @BotFather)
3. **Все зависимости** из `requirements.txt`

## 🚀 Быстрый старт

### 1. Создайте тестового бота

1. Напишите @BotFather в Telegram
2. Отправьте `/newbot`
3. Выберите имя и username для тестового бота
4. Скопируйте полученный токен

### 2. Настройте окружение

```bash
# Скопируйте пример конфигурации
cp env.local.example .env

# Отредактируйте .env файл
# Замените your_test_bot_token_here на токен вашего тестового бота
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Запустите тестирование

```bash
# Тест логики конвертации
python test_conversion.py

# Запуск тестового бота
python test_bot.py
```

## 🔧 Что тестируется

### ✅ Логика конвертации валют
- Правильность курсов покупки/продажи
- Спред между курсами
- Обратная конвертация

### ✅ RateHandler
- Получение курсов с BestChange
- Кэширование данных
- Конвертация валют

### ✅ Telegram бот
- Inline команды
- Callback кнопки
- Обработка ошибок

## 📁 Файлы для тестирования

- `test_bot.py` - основной тестовый бот
- `test_conversion.py` - тест логики конвертации
- `env.local.example` - пример конфигурации
- `test_bot_database.db` - тестовая база данных
- `test_cache/` - тестовый кэш

## 🛠 Настройки тестирования

В `.env` файле:

```env
# Тестовый бот
TEST_BOT_TOKEN=your_test_bot_token_here

# Быстрое тестирование
CACHE_DURATION=10          # 10 секунд кэш
RATE_LIMIT_COOLDOWN=5      # 5 секунд rate limit

# Отдельные файлы для тестов
DATABASE_PATH=test_bot_database.db
CACHE_DIRECTORY=test_cache
```

## 🧪 Примеры тестов

### Тест конвертации
```bash
python test_conversion.py
```

Ожидаемый результат:
```
💰 10,000₽ → USDT:
   10,000₽ ÷ 81.61₽ = 122.54 USDT

💵 124.98 USDT → ₽:
   124.98 USDT × 80.01₽ = 9999.70₽
```

### Тест бота
```bash
python test_bot.py
```

Бот запустится и будет отвечать на команды в Telegram.

## 🚀 Workflow разработки

1. **Разработка** - вносите изменения в код
2. **Локальное тестирование** - `python test_bot.py`
3. **Проверка** - тестируйте все функции
4. **Коммит** - `git add . && git commit -m "описание"`
5. **Пуш** - `git push origin main`
6. **Railway** - автоматически обновится

## 🐛 Отладка

### Логи
- Консольные логи в реальном времени
- Файл `test_bot.log` для истории

### База данных
- SQLite файл `test_bot_database.db`
- Можно открыть в DB Browser for SQLite

### Кэш
- Папка `test_cache/`
- Файл `rates_cache.json` с курсами

## ⚠️ Важно

- **НЕ используйте** продакшн токен для тестирования
- **Тестовая БД** отделена от продакшн
- **Кэш** очищается при каждом запуске тестов
- **Rate limiting** настроен на быстрые тесты
