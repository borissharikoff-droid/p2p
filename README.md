
Telegram-бот для получения актуальных курсов обмена USDT в рубли с сайта BestChange.

## 🚀 Возможности

- 💲 Получение актуальных курсов USDT/RUB
- 📈 Топ-5 лучших обменников
- 💼 Управление USDT кошельками
- 🔄 Inline-режим для конвертации валют
- 📊 Создание чеков для оплаты
- 🪙 Отслеживание криптовалют с уведомлениями
- ⚡ Кэширование и оптимизация
- 📈 Детальная аналитика

## 🛠️ Технологии

- **Python 3.8+**
- **python-telegram-bot** - Telegram Bot API
- **SQLite** - База данных
- **BeautifulSoup4** - Парсинг HTML
- **Requests** - HTTP запросы
- **Pandas** - Обработка данных

## 📦 Установка

### Локальная разработка

1. Клонируйте репозиторий:
```bash
git clone <your-repo-url>
cd telegram-bot
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` на основе `env.template`:
```bash
cp env.template .env
```

5. Заполните переменные в `.env`:
```env
BOT_TOKEN=your_bot_token_here
CACHE_DURATION=60
RATE_LIMIT_COOLDOWN=30
PORT=8080
```

6. Запустите бота:
```bash
python telegram_bot.py
```

## 🚂 Развертывание на Railway

### 1. Подготовка

1. Убедитесь, что все файлы загружены в GitHub
2. Создайте аккаунт на [Railway.app](https://railway.app)

### 2. Развертывание

1. Войдите в Railway и создайте новый проект
2. Выберите "Deploy from GitHub repo"
3. Подключите ваш репозиторий
4. Railway автоматически определит Python проект

### 3. Настройка переменных окружения

В панели Railway добавьте переменные:

```
BOT_TOKEN=your_bot_token_here
CACHE_DURATION=60
RATE_LIMIT_COOLDOWN=30
PORT=8080
```

### 4. Запуск

Railway автоматически:
- Установит зависимости из `requirements.txt`
- Запустит бота с помощью `Procfile`
- Откроет health check на `/health`

## 🐛 Устранение неполадок

### Бот не отвечает:
1. Проверьте токен в переменных окружения
2. Убедитесь, что бот запущен в Railway
3. Проверьте логи в панели Railway

### Ошибки парсинга:
1. Проверьте доступность BestChange
2. Убедитесь в актуальности селекторов
3. Проверьте логи парсера

### Проблемы с БД:
1. Убедитесь, что БД создается автоматически
2. Проверьте права доступа к файлам
3. Проверьте логи базы данных
