- **Цвета**: точно как в вашем примере

## 🚀 Как это работает

При нажатии кнопки **"Получить курс"** в Telegram боте:

1. Бот получает актуальные курсы с BestChange
2. Вызывается `image_generator.generate_currency_card()`
3. Создается изображение в новом стиле
4. Изображение отправляется в чат с подписью
5. Временный файл автоматически удаляется
